# ONE MORE BEAT

A one-finger rhythm survival game where the gameplay **is** the soundtrack.

## V3 — 20 Worlds

- 20 unlockable audio/visual worlds with their own palette, musical root/scale, signature phrase and transition feel
- 59 authored rhythm phrases/signatures across recovery, easy, medium, hard and elite difficulty
- Animated non-verbal obstacle language: rotating TAP diamond, charging HOLD wall and breathing WAIT ring — no distracting action words during live play
- Full song structure: intro, verse, build, drop, breakdown, second build and harder second drop
- Performance-driven adaptive difficulty: struggling runs receive a recovery phrase; highly accurate runs reach richer patterns sooner
- Performance-driven music mix with action-specific TAP plucks, HOLD charge/release sound and WAIT breathing space
- 10 challenge identities with distinct phrase mechanics including SWITCHBACK, HOLD PRESSURE, SILENCE TEST, RUSH, SYNCOPATION and NO BRAKES
- Dramatic world transitions with geometric tunnel changes and musical transition sweeps
- First-run interactive three-lesson tutorial; live-run words disappear after learning the shapes
- Daily Beat, Practice Mode and DOUBLE OR NOTHING preserved
- Shareable 1080×1080 run cards generated on-device from the death screen
- Optional restrained haptic rhythm feedback with a menu toggle
- Phone-latency timing grace and carried-HOLD fairness preserved
- Immediate silence on death and instant ONE MORE? restart
- Offline/PWA support and Android APK builds through GitHub Actions

## Controls

- Diamond: **TAP** as it reaches the timing line
- Wall: **HOLD** through it
- Ring: **WAIT** without touching

For the best experience, use headphones.

## Android

The latest APK is published automatically to the `android-latest` GitHub Release after a successful build.
